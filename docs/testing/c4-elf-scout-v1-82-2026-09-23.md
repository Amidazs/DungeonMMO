## Source-controlled backend increment

Four previously missing Elven Scout first-transfer source ranks
now have separately purchased, level-gated functional analogues:

| Original source rank | DungeonMMO ID | Source level | Gameplay |
| --- | --- | ---: | --- |
| Cure Wounds | `ElvenScoutCureWounds` | 24 | Genuine self-only 42 HP heal, 12 mana, 10-second cooldown. |
| Attack Buff | `ElvenScoutBattleFocus` | 28 | 8% timed physical-power bonus, 14 stamina, 22-second cooldown. Applies to real melee **and bow** damage. |
| Speed Buff | `ElvenScoutWindRun` | 32 | 10% actual WalkSpeed bonus, 16 stamina, 24-second cooldown; normal combat movement locks remain authoritative and speed resets after ten seconds. |
| Movement Slow | `ElvenScoutSnaringShot` | 36 | Longbow-only damaging projectile, 35% timed NPC slow on server-confirmed hit; one target, 24 stamina, 11-second cooldown. |

All four require Elf race, correct Ranger/Rogue base class
(Snaring Shot is Ranger-only), source level, purchased rank,
combat loadout and normal server skill request authorization.
The server uses its existing mana, stamina, cooldown, healing,
physical-damage, projectile-hit and NPC movement authorities.
They do not allow a second Gathering or Creation profession.
