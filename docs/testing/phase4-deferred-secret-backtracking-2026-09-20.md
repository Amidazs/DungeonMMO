# Phase 4 — deferred Secret-boss backtracking fix (20 September 2026)

## Scope and player report
Published TEST Temple user cleared Room1, bypassed a side arena, cleared Room2, then returned to two side arenas and neither activated. The code materializes at most one SecretBoss arena and one separately gated timed EventBoss arena in this TEST Temple Depth1 layout; two visibly accessible optional physical arenas do not imply two available Secret bosses.

The original runtime permanently persisted the optional Secret encounter as `Skipped` on entering its successor, and the sequencer rejected any skipped encounter. This fix allows an eligible skipped Secret to be started on backtracking **before dungeon completion**, without rewinding or blocking the required route. A not-yet-skipped Secret remains normally enterable after its prerequisite rooms have cleared.

## Changes and limits
- `DungeonEncounterSequencer`: a skipped, nonrequired `SecretBoss` can be started as a deferred side fight if a required encounter remains pending and no other encounter is active. It has a separate transient active marker for safe interrupted-run recovery. A failed setup or failed persistence restores the local skipped state and preserves the main route. Clearing it persists `Cleared` exactly once; repeats and post-completion entry are rejected. Required and Event bosses cannot use this path.
- `DungeonEncounterRuntimeController`, `DungeonEncounterFlow`: safely bridge a deferred Secret through the existing server-side execution registry and persistence, with explicit rollback if saving the start fails.
- `DungeonSecretDiscoveryService`: retains authoritative distance, connected/active membership and run-issued secret-unlock checks; permits a skipped but still eligible side route only while the next required encounter remains pending. An active, cleared or ineligible encounter is not discoverable.
- `DungeonRuntime.server.luau`: permits eligible backtracked Secret trigger activation before completion; it does **not** force an event or secret to become eligible. Inactive TEST Depth1 optional physical arenas attempt to show a concise eligibility explanation if their marker exists in the resolved authored/placeholder layout. Other dungeons, difficulties and their release gates remain unchanged.
- No live TEST or PROD place was published, no DataStore or player profile modified, no authored dungeon art/geometry changed. Existing event windows and server-selected secret chance/eligibility remain enforced. Previously persisted *completed* runs remain completed; existing secret runs marked `Skipped` can be visited while a subsequent required room is still pending and the original secret eligibility is still present.
