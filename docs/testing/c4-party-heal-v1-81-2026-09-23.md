## Implementation

- Human and Elven first-tier Mystics each have all three distinct
  `MysticPartyHeal` level-14 source ranks. Purchased Healing Prayer
  rank 3, an equipped Arcane Wand, legitimate trainer purchases,
  skill points, the authored rank/proficiency gates and equipped
  combat loadout remain required.
- Authoritative client skill requests consume one shared cast
  (28 mana, twelve-second cooldown), then restore actual HP to up
  to four in-range, living, injured, active party members. Actual
  per-member rank amounts are 34/44/56, modified by earned heal
  bonuses; every target's actual HP is individually capped.
- The party roster comes from `DungeonRuntime`'s genuine active
  server session, checking its caster and recipient member modes,
  connectivity, abandonment and authoritative combat eligibility.
  An unadmitted client, solo active member or spectator cannot
  become a party target by supplying an ID or modifying UI attributes.
- Source/target death, three-dimensional range, line of sight,
  missing party membership, effective healing and caster death
  are checked server-side before applying each real HP grant.
- The existing `MageHealService.apply_heal` callback records real
  per-target contribution, earned healing progression and hostile
  support threat; no cosmetic-only or free extra HoT ticks exist.
- UI can use the existing normal MageHeal combat presentation; no
  new bespoke art/animation is claimed accepted.
